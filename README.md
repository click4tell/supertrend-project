- **فرم پرداخت**: USDT (TRC20) و کارت بانکی + قیمت لحظه‌ای تتر.
- **ربات رایگان**: استراتژی Pine Script تریدینگ ویو به‌صورت رایگان ارائه می‌شود.

## 🛠️ نحوه انتشار / Deployment

1. فایل‌ها را به ریپوی GitHub (Branch: `gh-pages` یا Main با GitHub Pages) Push کنید.
2. دامنه `mql5expert.ir` را روی Cloudflare به GitHub Pages وصل کنید.
3. در Cloudflare: **Caching → Configuration → Crawler Hints** را روشن کنید.
4. بعد از هر تغییر: **Purge Cache** را بزنید.
