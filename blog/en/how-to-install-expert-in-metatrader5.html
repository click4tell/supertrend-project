How to Install an Expert Advisor in MetaTrader 5 (Step-by-Step)

Published: August 17, 2026 | Category: Tutorial

One of the first questions after buying an Expert Advisor or trading robot is how to install it in MetaTrader 5. This step-by-step guide shows you exactly how to install and enable an EA on the MT5 platform.

Prerequisites

  • MetaTrader 5 installed (download it from your broker).
  • The .ex5 file of your robot.
  • (Optional) a .set settings file if provided with the robot.

Step 1 — Find the Data Folder

In MetaTrader 5, open the File menu and select Open Data Folder. A Windows window will open showing the MT5 data directory.

Step 2 — Copy the Expert File

Inside the Data Folder, go to:

MQL5\Experts

Copy the .ex5 file into this folder. Note that robots can only be loaded from the Experts folder; the Indicators folder is for indicators.

Step 3 — Refresh the Navigator

Back in MetaTrader, right-click Expert Advisors in the Navigator panel (left side) and choose Refresh. Your robot should now appear in the list.

Step 4 — Attach the Robot to a Chart

Drag the EA from the Navigator onto your chart. The settings window will open:

  • Inputs tab: the EA's parameters (lot size, stop loss, etc.).
  • Common tab: checkboxes such as Allow Algo Trading.

Click OK when done.

Step 5 — Enable AutoTrading

Find the AutoTrading button in the MT5 toolbar and make sure it is enabled. Also verify this setting:

Tools → Options → Expert Advisors → Allow Algorithmic Trading

⚠️ Note: If AutoTrading is off or Allow Algorithmic Trading is unchecked, the robot will not trade and its icon on the chart will turn grey.

Test on a Demo Account

Before using real money, test the robot for at least a few weeks on a demo account, and preferably run a backtest in the Strategy Tester to review its performance.

Common Problems and Fixes

  • Grey/inactive robot: enable AutoTrading or Allow Algorithmic Trading.
  • Robot opens no trades: not enough balance/margin, or the price distance is below the broker's stops level.
  • ex5 file not visible: copy the file to the correct folder and Refresh; if the file is protected, use it only with your broker.
