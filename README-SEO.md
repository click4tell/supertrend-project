## 📁 محتویات پکیج

| فایل | کجا قرار بگیرد | توضیح |
|------|----------------|--------|
| `index.html` | ریشه ریپوی گیتهاب (جایگزین `index.html` فعلی) | ⭐ نسخه کامل و بهینه‌شده سایت شما — همین را آپلود کنید |
| `sitemap.xml` | ریشه ریپوی گیتهاب (کنار `index.html`) | نقشه سایت برای گوگل و بینگ |

| `README-SEO.md` | ریشه ریپو (اختیاری) | همین راهنما |

## ✨ تغییراتی که روی `index.html` اعمال شده

1. **زبان پیش‌فرض فارسی** → `<html lang="fa" dir="rtl">` (گوگل سایت را فارسی می‌بیند)
2. **متن فارسی در HTML** → همه متن‌ها فارسی قابل مشاهده‌اند؛ انگلیسی در `data-en` (قابل ایندکس شدن برای «ربات فارکس»، «اکسپرت» و...)
3. **head جدید** → عنوان بهینه، Canonical، Open Graph، Twitter Card
4. **۴ نوع Schema** → WebSite، Organization، Product (۴ محصول)، FAQPage
5. **ایمیل خراب اصلاح شد** → لینک `mailto:info@tsgcoltd.ir` واقعی
6. **یک H1 در صفحه** → عنوان «محصولات ما» به H2 تغییر کرد
7. **alt تصاویر فارسی** + **نام و توضیح محصولات به‌صورت متن ثابت** (حتی اگر جاوااسکریپت کار نکند)
8. **باگ جاوااسکریپت اصلاح شد** → فوتر و باکس سلب مسئولیت هنگام سوییچ زبان دیگر خراب نمی‌شوند

## 🚀 مراحل اجرا (به ترتیب)

### قدم ۱ — آپلود فایل‌ها
1. `index.html` جدید را جایگزین فایل فعلی در ریشه ریپو کنید (فایل قبلی را برای پشتیبان در Downloads نگه دارید).
2. `sitemap.xml` را در ریشه ریپو قرار دهید.
3. Commit و Push کنید.

### قدم ۲ — Cloudflare
1. داشبورد Cloudflare → **Caching → Configuration → Crawler Hints** را روشن کنید.
2. **Caching → Purge Everything** بزنید تا نسخه جدید نمایش داده شود.

### قدم ۳ — Google Search Console
1. به `search.google.com/search-console` بروید.
2. دامنه `mql5expert.ir` را اضافه و تایید کنید (از طریق DNS کلودفلر).
3. `sitemap.xml` را در بخش Sitemaps سابمیت کنید.
4. در بخش URL Inspection، آدرس صفحه اصلی را بررسی و «درخواست ایندکس» بدهید.

### قدم ۴ — تولید محتوا (برای رتبه گرفتن در «ربات فارکس» و «اکسپرت»)
1. پوشه `blog/` در ریپو بسازید.
2. `blog-article-template.html` را با نام مناسب کپی کنید (مثلاً `blog/what-is-forex-robot.html`).
3. عنوان، توضیحات، canonical و متن را عوض کنید (متن حداقل ۵۰۰ تا ۸۰۰ کلمه).
4. آدرس مقاله را به `sitemap.xml` اضافه کنید.

### قدم ۵ — Bing Webmaster Tools (اختیاری)
سایت را به `bing.com/webmasters` اضافه کنید و sitemap را سابمیت کنید.

## ⚠️ نکات مهم

- **از عبارت «سود تضمینی» و «پولدار شدن» استفاده نکنید** — گوگل و قوانین فارکس این ادعاها را جریمه می‌کنند. همیشه ریسک را ذکر کنید.
- اگر محصول جدید اضافه کردید: یک بلوک `Product` به JSON-LD داخل `index.html` و یک آیتم به `sitemap.xml` اضافه کنید.
- بعد از هر تغییر در ریپو: Cloudflare را Purge کنید و در Search Console درخواست ایندکس بدهید.
